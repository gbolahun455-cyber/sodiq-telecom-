# SODIQ TELECOM SERVICES - Phase 1

Website files only (homepage, login/register screens, dashboard layout).
Login and registration are NOT connected yet. That happens in Phase 2.

## Put it on GitHub from your phone
1. Unzip this file on your phone (Files by Google -> long-press the zip -> Extract).
2. On github.com open your sodiq-telecom repo -> Add file -> Upload files.
3. Upload the extracted files and folders (src, package.json, index.html, etc.).
   Tip: if folders will not upload from the mobile browser, use Codespaces
   (drag the folder into the Explorer) or create the files one by one.
4. Commit changes.
5. On vercel.com: Add New -> Project -> import the repo -> Deploy.
